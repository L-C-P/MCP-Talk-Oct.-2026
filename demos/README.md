# Demo Projects

This folder contains demo project workspaces used during the MCP talk and live coding sessions.

## Demo projects
- `StarAgent.McpServer.Shared` – shared capabilities used by stdio and HTTP servers
- `StarAgent.McpServer.Stdio` – local MCP server over stdio
- `StarAgent.McpServer.Http` – MCP server over Streamable HTTP
- `StarAgent.McpServer.AzureFunctions` – serverless MCP hosting on Azure Functions
